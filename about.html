Capstone & IoT Project

Project Title
tRoot: AI-Driven Multi-Node System for Soil Monitoring with Real-Time Adaptive Gardening Recommendations through Visualized Soil Viability Tracking
Description
an AI-driven multi-node soil monitoring system designed for micro-scale gardening — residential gardens, home nurseries, and small-scale growers in the Philippines. It uses an ESP32 microcontroller with five capacitive soil moisture sensors and a DHT22 temperature/humidity sensor to continuously track environmental conditions across multiple plant pots, syncing data to Firebase in real time. The system provides AI-powered plant recommendations based on manually inputted soil pH along with sensor-derived moisture, temperature, and humidity, and includes AI plant and soil identification features to help users make data-driven gardening decisions and avoid "silent crop failure."
Objectives

1. Design and construct a multi-node edge hardware architecture using an ESP32 microcontroller, a DHT22 atmospheric sensor, and five capacitive soil moisture sensors (V1.2) to capture localized temperature, humidity, and per-pot substrate moisture.

2. Establish a secure, low-latency cloud synchronization link between the edge device and a Firebase Realtime Database, with accurate timestamping via NTP for seamless remote access through web and mobile interfaces.

3. Develop a Sensor-Based AI Recommendation Engine that processes moisture, pH, temperature, and humidity data to generate automated plant suitability recommendations for Philippine-native and locally available species, including detailed care guides.

4. Implement centralized, cross-platform web and mobile applications (Next.js/React web app and Flutter mobile app) that visualize real-time telemetry, historical logs, and AI recommendations.

5. Validate operational reliability and decision-making accuracy through structured field testing, measuring data transmission success rates and evaluating the biological relevance of generated plant recommendations.

Technologies Used
ESP32 Microcontroller DHT22 Sensor 5x Capacitive Soil Moisture Sensors (V1.2)
